# 바이브코딩 클로드 실습

Claude Code로 만들어 본 작은 웹 앱과 자동화 도구 모음입니다.

## 프로젝트 목록

| 폴더 | 설명 | 기술 |
|------|------|------|
| `Hello-world` | 첫 웹 페이지 | HTML, CSS |
| `Counter`, `count` | 카운터 앱 | HTML, CSS, JavaScript |
| `My-Portfolio` | 자기소개 포트폴리오 페이지 | HTML, CSS, JavaScript |
| `Snake game` | 스네이크 게임 | HTML, CSS, JavaScript |
| `To do` | 할 일 관리 앱 (추가·완료·삭제·필터, LocalStorage 저장) | HTML, CSS, JavaScript |
| `fxconveter` | 환율 변환기 | HTML, CSS, JavaScript |
| `홍보자동화` | 매장 사진을 인스타그램용(1080x1080)으로 변환하고 로고를 넣은 뒤 SNS 홍보 문구를 만들어 주는 도구 | Python |

> `My-todo-app`, `단골 적립 스탬프`, `메뉴판`은 별도의 Git 저장소로 관리되어 이 저장소에는 링크로만 포함되어 있습니다.

## 실행 방법

- **웹 앱**: 각 폴더의 `index.html`을 브라우저로 열면 됩니다. 별도의 설치나 빌드가 필요 없습니다.
- **홍보자동화**: `홍보자동화/사용설명서.txt`를 참고해 `실행.bat`을 실행합니다.
