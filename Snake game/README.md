# 스네이크 게임 (Snake Game)

HTML Canvas와 바닐라 JavaScript로 만든 클래식 스네이크 게임입니다. 빌드 도구나 외부 라이브러리 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다.

```bash
git clone https://github.com/bridgeaiedu-jsu/Snake-game-app.git
cd Snake-game-app
```

VS Code를 쓴다면 Live Server 확장으로 열어도 됩니다. 별도의 설치나 빌드 과정은 없습니다.

## 게임 방법

- **방향키(↑ ↓ ← →)** 로 뱀을 조종합니다
- 빨간 먹이를 먹으면 뱀이 한 칸 길어지고 **+10점**
- **벽**이나 **자기 몸**에 부딪히면 게임 오버
- 진행 방향의 정반대 키는 무시됩니다 (즉사 방지)

## 주요 기능

### 난이도 선택

시작 전은 물론 게임 도중에도 바꿀 수 있고, 즉시 반영됩니다.

| 난이도 | 이동 간격 |
| --- | --- |
| 쉬움 | 200ms |
| 보통 (기본값) | 150ms |
| 어려움 | 100ms |
| 매우 어려움 | 50ms |

### 레벨 시스템

- **50점마다** 레벨이 1씩 오릅니다 (`레벨 = 점수 / 50 + 1`)
- 레벨이 오를 때마다 이동 간격이 **10ms씩 짧아집니다** (= 속도 상승)
- 조작이 불가능해지지 않도록 최소 간격은 **30ms**로 제한됩니다

### 일시정지

일시정지 버튼으로 언제든 멈추고 이어서 할 수 있습니다. 버튼 텍스트가 `일시정지` ↔ `이어하기`로 바뀌고, 정지 중에는 방향키 입력이 무시됩니다.

### 최고 점수 저장

최고 점수는 브라우저 `localStorage`(키: `snake-best-score`)에 저장되어 새로고침해도 유지됩니다. 신기록을 세우면 게임 오버 화면에 표시됩니다.

## 파일 구조

```
.
├── index.html   # 캔버스, 점수 패널, 난이도/일시정지 컨트롤, 상태 오버레이
├── style.css    # CSS 변수 기반 테마, 카드 레이아웃, 반응형 대응
└── main.js      # 게임 루프, 충돌 판정, 레벨/속도 계산, 렌더링
```

## 구현 메모

- **보드**: 400×400 캔버스를 20px 셀로 나눈 20×20 격자
- **입력 처리**: 키 입력을 `pendingDirection`에 모았다가 틱 시작 시점에만 반영합니다. 한 틱 안에 두 번 꺾어서 자기 몸에 박히는 문제를 막기 위함입니다
- **충돌 판정**: 꼬리를 먼저 제거한 뒤 검사하므로, 비켜나는 꼬리 자리로 들어가는 것은 충돌로 보지 않습니다
- **먹이 배치**: 빈 칸 목록을 만들어 그 중에서 뽑습니다. 뱀 위에 겹치지 않으며 재시도 루프가 없습니다
- **속도 관리**: 난이도 변경·레벨업·일시정지·재개·게임 오버가 모두 `applySpeed()` 하나를 거쳐 타이머를 다시 걸기 때문에 타이머가 중복으로 도는 경우가 없습니다
- **접근성**: 점수 영역 `aria-live`, 방향키 `preventDefault()`로 페이지 스크롤 방지, `prefers-reduced-motion` 대응

## 기술 스택

HTML5 Canvas · CSS3 · Vanilla JavaScript (ES6+) · Web Storage API
