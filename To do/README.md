# 나의 할 일 목록 (Todo App)

HTML, CSS, JavaScript만으로 만든 간단한 할 일 관리 웹 앱입니다. 별도의 빌드나 설치 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **할 일 추가** — 입력 후 `추가` 버튼 또는 Enter 키
  - 빈 값이나 이미 등록된 할 일은 추가되지 않고 안내 메시지가 표시됩니다.
- **완료 체크** — 체크박스로 완료/미완료 전환
- **삭제** — 항목별 `삭제` 버튼, `완료된 항목 삭제`로 완료 항목 일괄 삭제
- **필터** — 전체 / 진행중 / 완료
- **개수 표시** — "전체 N개, 완료 N개"
- **자동 저장** — LocalStorage에 저장되어 새로고침해도 목록이 유지됩니다.

## 사용 방법

1. 저장소를 내려받습니다.
   ```
   git clone https://github.com/ekdud942-cloud/to--do.git
   ```
2. `index.html`을 브라우저로 엽니다.

## 파일 구조

```
├── index.html   # 화면 구조
├── style.css    # 스타일
└── main.js      # 할 일 추가·삭제·필터·저장 로직
```

## 기술 스택

- HTML5
- CSS3
- JavaScript (ES6, 외부 라이브러리 없음)
